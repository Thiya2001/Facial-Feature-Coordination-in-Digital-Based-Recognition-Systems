![image](https://github.com/user-attachments/assets/a5d165d2-768f-4f7d-9e13-437f523ccf82)# Facial-Feature-Coordination-in-Digital-Based-Recognition-Systems
A facial recognition-based criminal detection system using Python and MySQL, enabling criminal data registration, real-time CCTV surveillance, and optimized performance on low-end devices with CSV support for easy integration.

How to setup

pip install Pillow==8.4.0
pip install opencv-python==4.11.0.86
pip install numpy==1.23.5
pip install pymysql==1.1.1

How to run

python home.py
